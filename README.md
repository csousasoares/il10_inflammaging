# Chronic exposure to interleukin-10 drives inflammaging and accelerated tissue senescence

Repository for the paper "Chronic exposure to interleukin-10 drives inflammaging and accelerated tissue senescence"

## Contents

JPC_mouse_data - Code for GSEA and age-correlation analyses for mouse cells/tissues in Fig 4b-e, Fig. S1f, Fig. S4b-c and Fig. S5b-d

TMS_UCell_analysis - Code for the UMAP plots from the Tabula Muris Senis (IL-10 signature) in Fig. 4a and Fig. S5a.

Plasma_proteome_analysis - Code for the analysis of plasma proteome changes (IL-10 signature) with age in Fig. 5a.

Aging_il10_signature_human - Code for GSEA of the signature in human immune cells in Fig. 5b.

UMAP_human_aging - Code for the UMAP plots in Fig. 5c and Fig. S6a.
